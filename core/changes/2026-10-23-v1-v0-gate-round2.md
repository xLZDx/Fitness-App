# Change record: V0 gate round 2 fixes (2026-10-23)

Base: 4c534542. Answers the three findings of the second GPT-PM code gate on slice V0.

## What changed
- mobile/lib/features/workouts/offline/file_command_queue_store.dart: the seq.json / logical_sets.json primary+backup scheme is replaced by one metadata document {format 2, gen, seq, logicalSets} with a sha256 line, stored in two slots (meta.a.json, meta.b.json); a write goes to the slot without the highest valid generation via atomic temp+rename; load takes the valid slot with the highest generation, keeps a corrupt slot as .corrupt-n; store.init marks an initialized store, and an initialized store without a valid slot fails closed (QueueRecoveryRequiredException).
- command_queue_store_base.dart: one persistMetadata call replaces the two persist calls; accept is idempotent for the same operation id or intent key (a record that survives a failed rollback is re-adopted, the sequence counter is raised).
- in_memory_command_queue_store.dart, command_queue_store.dart: adapted to the single metadata call.
- Tests: stale primary/backup tests rewritten to the new contract; new regression tests for the GPT sequences after pruning (both slots deleted or garbage, stale unchecksummed slot never selected, write fault plus cleanup fault then restart and identical retry).
