# S02-10 change record: A-1..A-3 interfaces

Date: 2026-10-16. Story: S02-10 (design 1 and 9; test ids U14, U15, U16).

## What changed

- New `mobile/lib/features/activity/data/activity_quarantine.dart` (A-1): `quarantineCheck(raw, {limits})` scans raw JSON text for size, nesting depth (32), string length (1 MiB), duplicate object keys, then decodes and checks per-stream sample counts (200 000) and non-finite numbers. Returns the decoded object or a `QuarantineReason`; never throws. No importer and no file access.
- New `mobile/lib/features/activity/data/source_cursor.dart` (A-2): `SourceCursor(sourceId, cursor, windowInclusive)` with JSON round trip; `tryParse` / `tryParseFor` turn a missing, corrupt or foreign cursor body into null ("no cursor") instead of throwing.
- `device_source.dart` (A-3): `DeviceSource` gains `healthStatus()` (new enum `SourceHealth`), `deleteCached()` and an optional `streamDuringWorkout` with an empty default. There is deliberately no write-back method. `fake_device_source.dart` implements them.

## Why

Design 1 and 9: interfaces and local state only. No cross-source (external) dedup is claimed or implemented; the only dedup is the native-id rule and merger rules 0/1.

## Deviations

- `windowInclusive` is a bool (the design names the field only). Because `implements DeviceSource` cannot inherit defaults, any other implementer must define `streamDuringWorkout` itself.

## Verification state

No tests, builds or checks were run (operator rule v4). Test agents own U14, U15, U16.
