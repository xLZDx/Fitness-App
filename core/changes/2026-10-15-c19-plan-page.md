# C19 plan page, review card, entry card (part 2)

What: `mobile/lib/features/nutrition_plan/nutrition_plan_page.dart` (route
`/nutrition`), `widgets/review_card.dart` (why-card with closed reason codes,
7-day undo for coached, accept for shared), `widgets/nutrition_entry_card.dart`
(`NutritionEntryCard`, exported only; Progress/Home are owned by C17 and do not
mount it here).

Behaviour: verdict gates the screen (`referProfessional` shows only the
professional notice; `needsAnswer`/`needsProfile` link to `/nutrition/profile`).
Plan creation and every edit go through `ensureDataNoticeAcknowledged` and
`NutritionPlanActions`. The first display calls
`run(ReviewTrigger.planSurfaceShown)`. Neutral target copy, no ETA, scans
best monthly, pause toggle (`BodyScanSettingsStore.setPaused`).

Contracts: uses `nutrition*`, `reviewReason*`, `planTone*`, `weightLog*` l10n
keys from the C19 ARB commit. No tests run.
