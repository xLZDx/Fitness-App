Date: 2026-10-16. Story: S02-05b (design 4 closing check, 5.3; test ids F40, F88).

## What changed

- `firestore.indexes.json`, merged with the existing entries (none removed or reordered):
  - composite index, collection group `activity_streams`, scope COLLECTION_GROUP: `state` ASC + `expiresAt` ASC (the purge candidate query and the oldest-overdue query).
  - field override, collection group `activity_settings`, field `recomputePending`: single-field index also enabled at COLLECTION_GROUP scope (the recompute discovery query `recomputePending == true`); the two default COLLECTION indexes are listed again because an override replaces the defaults.

## Why

A collection-group query without a matching index fails with FAILED_PRECONDITION; the purge turns that into the missing-index signal (design 6.3), but production must have both entries.
