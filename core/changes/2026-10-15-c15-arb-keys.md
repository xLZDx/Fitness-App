# C15 change record: body scan flow and result ARB keys

Story: C15 `body-scan-flow-and-result` (sprint plan row C15), part 1 of 4.

## What changed
- `mobile/lib/l10n/app_en.arb` and `mobile/lib/l10n/app_ru.arb`: about 150 new keys, all prefixed `bodyScan*` or `checkCode*`.
  - intro, weight prompt, analysis stages and live-region copy, result view, provisional banner and rough-estimate label, change labels, noise note, weight trend, strength sessions, plan action.
  - "check these" chip states, the 13 closed `CheckCode` texts (`checkCode<Name>`, matching `CheckCode.l10nKey`).
  - chart summary sentences, data-table labels, legend, cloud consent sheet, resume card and terminal failure actions (D-78).
- RU plurals use one/few/many/other. Decimal quantities are passed as pre-formatted strings (locale-aware `NumberFormat` in the widgets, D-85) and use non-inflecting units (`кг`, `п.п.`, `нед.`).

## Why
Design sections 10, 12, 17 (D-73, D-74, D-78, D-81, D-85): all user-visible strings of the C15 widgets are localized.

## Affected contracts and paths
- Generated `AppLocalizations` gains the new getters after `flutter gen-l10n` (not run here, by operator rule; test agents run it).
- No existing key was changed.
