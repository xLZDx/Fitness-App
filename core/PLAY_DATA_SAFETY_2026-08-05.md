## 2. Data types

"Shared" throughout is **No**. Play defines sharing as transfer to a *third
party*; Google (Firebase) and Stripe are service providers processing on the
operator's instructions, which Play's own guidance excludes from "shared".
Firebase states the same for its side: *"Firebase does not transfer collected
data to third parties except to subprocessors assisting with Firebase
services"* (firebase.google.com/docs/android/play-data-disclosure).

## 3. Data types explicitly NOT collected

Ticking these by accident is a common cause of rejection, so they are recorded
here as deliberate "No" answers:

- Location (approximate or precise) — no location permission, no geo field
- Contacts, Calendar, SMS, Call logs — no such permission
- Web browsing history, Installed apps, Search history
- Sexual orientation, Race and ethnicity, Political or religious beliefs
- Audio — the app plays cue sounds, it does not record
- Videos — the catalog *serves* clips; none are captured from the user
- Advertising ID — no ad SDK exists in the project
