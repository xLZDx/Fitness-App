# B5 — откуда брать картинки: измерено, а не предположено (2026-08-07)

Гейт упёрся в данные. Ниже — что проверено, чем именно, и какие пути остались.

## 1. Существующий краулер мёртв

`crawl_dataset.py` (icrawler + Bing) построил v1 29.07. Сегодня он возвращает
**ноль** изображений. Проверено попарно, чтобы отделить фильтр от поломки:

```
hip abductor, БЕЗ фильтра лицензии : 0
hip abductor, commercial,modify    : 0
treadmill,    commercial,modify    : 0
treadmill,    creativecommons      : 0
```

Ноль без фильтра означает, что дело не в лицензии. Сеть при этом жива:
`bing.com/images/search` отвечает **HTTP 200**, `raw.githubusercontent.com`
отвечает 200. То есть сломан **парсер** icrawler — Bing изменил выдачу после
29.07.

Починка — это правка скрейпинга чужой верстки, хрупкая по определению. И она
даёт лишь *заявление* поисковика о лицензии, что формулировку оператора
(«если в метаданных нет запрета») как раз не удовлетворяет.

## 2. Фильтр лицензии в краулере всё же есть

`icrawler.builtin.bing.BingFeeder.get_filter` поддерживает
`publicdomain`, `creativecommons`, `commercial`, `commercial,modify`.
`crawl_v2.py` его выставляет. Работать это начнёт только после починки парсера.

## 3. Wikimedia Commons: лицензии настоящие, объёма нет

Единственный проверенный источник, где лицензия лежит **в метаданных файла**, а
не в обещании поисковика: API отдаёт `extmetadata.LicenseShortName` —
`CC BY 4.0`, `CC BY-SA 3.0`, `Public domain`. Требует User-Agent, иначе 403.

Замер по всем 70 классам (`gsrlimit=100`, поиск по `filetype:bitmap`):

```
всего доступно на 70 классов :  561 изображение
классов с >= 50              :  2 / 70
классов с НУЛЁМ              : 25 / 70
```

25 классов с нулём включают `hip_abductor_adductor` — ровно ту машину, что на
фото оператора получила `treadmill` 0.892.

561 картинка на 70 классов это ~8 на класс. Обучению нужно 100+. **Commons не
может собрать этот датасет** — и это измерение, а не впечатление.

## 4. Что из этого следует

Бесплатных, корректно лицензированных фотографий **конкретных тренажёров** в
свободных источниках столько, сколько нужно, — не существует. Это не вопрос
усилий; это посчитано.

Остаются три пути, в порядке ценности:

**A. Съёмка своего зала оператором.** Наивысшая ценность и ноль лицензионных
вопросов: снимки принадлежат ему. 30 фото за один заход уже дали единственную
реальную выборку в проекте. 69 машин по 20-30 кадров — это пара заходов, и это
буквально то, что README модели называет главным выигрышем v2: *«real gym
photos at user angles»*. Плюс это данные, которых нет ни у одного конкурента.

**B. Roboflow Universe.** Готовые датасеты gym equipment на тысячи кадров,
многие CC-BY, лицензия указана у датасета. Нужен бесплатный API-ключ —
действие оператора, я его завести не могу.

**C. Починить парсер Bing.** Даёт объём, но каталожного вида (та самая причина
0.617 у v1) и с лицензией-заявлением. Наименее ценный путь из трёх.

A и B дополняют друг друга: B даёт объём для редких классов, A даёт реальные
углы для тех машин, что у оператора действительно стоят.

  `adjustable_bench` устранён.
