# Handoff: Fitness app — HUD glass UI (light + dark)

## Overview
Мобильное фитнес-приложение: домашний экран, каталог тренировок, скан тренажёра, активный подход, прогресс, профиль и экран AI-тренера с разбором техники по видео. Визуальная идея — **парящее HUD-стекло поверх живой фотографии**: фон меняется по времени суток, интерфейс держится тонким светящимся контуром почти без заливки.

## About the design files
Файлы в бандле — **дизайн-референсы, написанные на HTML** (прототипы вида и поведения), а не production-код для копирования. Задача — **воспроизвести эти экраны в целевой кодовой базе** (React Native / SwiftUI / Flutter / React web) её собственными паттернами и библиотеками. Если проекта ещё нет — выбрать подходящий фреймворк и реализовать в нём.

Формат `.dc.html` — внутренний формат дизайн-инструмента: разметка внутри `<x-dc>` + класс логики в `<script type="text/x-dc">`. Читать как «шаблон + компонент»: `{{ x }}` — подстановка значения, `<sc-for list as>` — список, `<sc-if value>` — условие, `<dc-import name>` — вложенный компонент. `support.js` — рантайм инструмента, **в продукт не переносить**.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы и состояния финальные — воспроизводить попиксельно. Единственное упрощение: распознавание позы в `Fitness Form Coach Phone` симулировано (таймер + тригонометрия), в продукте это реальный pose-estimation.

### Стекло — тёмная тема (главная формула)
```css
background: rgba(255,255,255,.014);
backdrop-filter: blur(7px);
box-shadow: inset 0 0 0 1px rgba(255,255,255,.34),
            0 0 26px -6px rgba(255,255,255,.26);
text-shadow: 0 1px 14px rgba(6,8,18,.85);
```
- Кнопка (самый светлый элемент): заливка `rgba(255,255,255,.05)`, контур `.46`, свечение `0 0 28px -8px rgba(255,255,255,.35)`; hover — `translateY(-2px)` + заливка `.12`, контур `.6`; active — заливка `.2`, `translateY(0)`. Переход `.18s ease` по `transform, background, box-shadow`.
- Мелкие чипы: заливка `rgba(255,255,255,.02)`, контур `rgba(255,255,255,.28)`.
- Дорожки индикаторов: `rgba(255,255,255,.16)`; заполнение — акцент + `0 0 12px -2px <accent>`.

## Screens / Views

Все шесть основных экранов живут в одном компоненте (`Fitness Glass Phone v1 - Sunset` — тёмная, `… - Light` — светлая) и переключаются табами. Стек: фото (`<img>`/`<video>` cover) → вуаль-градиент → контент → таб-бар.

### 1. Home (tab 0)
- Статус-бар 46 px: время слева, тройка иконок справа, `text-shadow` для читаемости.
- Приветствие: 800/22px + строка-подпись 400/11px.
- Панель дня: круглый счётчик упражнений (158×158, число 400/54px) + метаданные; кнопка «Начать» — самый светлый элемент, надпись слева, иконка справа.
- Недельная полоса: 7 чипов 20 px, выбранный — сплошной акцент с тёмным текстом; отмеченные дни — точка `rgba(255,255,255,.85)`.
- Быстрый переход в скан — строка-стекло с иконкой.
- Состояния: день тренировки / день отдыха (кнопка теряет свечение, копия про восстановление).

### 2. Workouts (tab 1)
Две подвкладки (`subTab` 0/1): «Программы» — текущая программа сверху + список; «Каталог» — горизонтальные чипы фильтров (5 шт.) и список упражнений. Выбранный чип — сплошной акцент; счётчик найденного обновляется под чипами.

### 3. Scan (tab 2)
Рамка наведения — четыре уголка `2px solid rgba(255,255,255,.9)` (светлая: `rgba(27,32,48,.42)`), больше плотной графики на экране нет. Состояние «найдено» (`scanned`) — карточка совпадения с круглым процентом и кнопкой перехода к упражнениям.

### 4. Progress (tab 3)
Столбцы объёма по неделям (у каждого контур, чтобы не растворялся в прозрачной панели), календарь-месяц точками, блок личных рекордов.

### 5. Profile (tab 4)
Строки настроек в стеклянных рамках, разделители заменены воздухом; тумблеры 50×29, ход 21 px, включённый светится акцентом, ручка 23 px белая с тенью.

### 6. Session (`view = "session"`)
Крупный круг прогресса подхода (SVG, `stroke-dasharray`, `rotate(-90deg)`, `drop-shadow`), список сетов (done / current / pending — цвета `#7BF08A` / текст / `rgba(...,.45)`), нижний блок: −/+ и главная кнопка «Сет закрыт». Таймер отдыха идёт живьём, кнопка меняет подпись, не форму.

### 7. Onboarding (`Fitness Onboarding - Dark / - Light`)
Девять шагов, один вопрос на экран, у каждого свой фоновый кадр: 1 Welcome (обещание одной фразой) · 2 Цель (4 карточки) · 3 Опыт (круглые цифры 1–2–3) · 4 График (чипы дней + круглый счётчик 158 px + тумблер напоминания) · 5 Параметры (два слайдера с числом 400/34px + переключатель единиц) · 6 Оборудование (мультивыбор чипами) · 7 Камера (запрос доступа, превью скелета со свечением, три строки про приватность) · 8 Фон (сетка 9:16, первая плитка — загрузка своего снимка) · 9 Готово (круг «12 недель» + сводка из 4 строк).
Полоса прогресса сверху из 9 сегментов, заполненные — акцент со свечением. «Пропустить» справа вверху ведёт сразу к шагу 9 на дефолтных ответах. Внизу пара: круглая кнопка «назад» 52 px (на первом шаге opacity .35) и главная кнопка — единственный светящийся элемент.
Состояние: `step` 1–9 + выбранные цель, уровень, дни, оборудование, фон, единицы, напоминание.

### 8. Form coach (`Fitness Form Coach Phone`)
- Слой 1: видео тренирующегося, `object-fit:cover`, `object-position:42% center`, `filter: saturate(.85) brightness(.72) contrast(1.02)`.
- Слой 2 (подсветка скелета): то же видео, `mix-blend-mode:screen; opacity:.9; filter: grayscale(1) brightness(.62) contrast(7) sepia(1) hue-rotate(62deg) saturate(6)` — светятся только яркие линии. **В продукте это заменяется реальным pose-overlay:** кости 3–3.4 px, цвет `#FFFFFF`, свечение `drop-shadow(0 0 5px)` + `drop-shadow(0 0 14px)` зелёным `rgba(110,255,130,.9)` при верной технике и красным `rgba(255,70,70,.95)` при ошибке; сустав с ошибкой — пунктирный круг r=26, `4 6`, пульсация 1.1 s.
- Сканирующая линия: горизонтальный градиент 2 px, проход 3.6 s.
- Два круглых счётчика (158×158): «Повторы» (`08 / 10` + полоса) и «Техника» (`94 %`, цвет по состоянию + подпись фазы «тяга вниз / возврат»).
- Подсказки: максимум две строки — одна подтверждающая, одна корректирующая (янтарная).
- Нижняя панель: 4 метрики (Темп, Амплитуда, Симметрия, Пауза) + пауза и «Закрыть сет».

## Interactions & Behavior
- Табы переключают экран мгновенно, без анимации перехода.
- Кнопки: `translateY(-2px)` на hover, обратно на active, `.18s ease`.
- Таймер отдыха и счётчики — тик 1 s / 110 ms; повтор = 12 тиков, счётчик щёлкает в верхней точке.
- Ошибка техники в прототипе срабатывает на каждом 4-м повторе в нижней фазе → счётчик 78 %, цвета в красный, появляется корректирующая подсказка.
- Смена фона: кроссфейд `opacity 1.6s ease` между шестью слоями-кадрами; активен слой текущей фазы.
- Скан: тап по рамке переключает «наведение → найдено».

## State Management
| Состояние | Тип | Назначение |
| --- | --- | --- |
| `tab` | 0–4 | активный раздел |
| `view` | `home` \| `session` | оверлей активной тренировки |
| `subTab` | 0–1 | подвкладка Workouts |
| `filter` | 0–4 | фильтр каталога |
| `scanned` | bool | результат скана |
| `day` | 0–6 | выбранный день недели |
| `done` | int | закрытых подходов |
| `rest` | сек | таймер отдыха |
| `hour` | −1..23 | −1 = живое время устройства |
| `photoSet` | `a` \| `b` | набор фонов |
| `theme` | light \| dark | в прототипе — два файла, в продукте один флаг |

Данные (программы, упражнения, рекорды, календарь) в прототипе — константы в начале класса логики; в продукте это API/локальная база.

## Backgrounds (важная часть продукта)
Шесть фаз суток по часам устройства: night 22:00–04:59 · dawn 05:00–06:59 · morning 07:00–10:59 · day 11:00–15:59 · golden 16:00–18:59 · dusk 19:00–21:59. Два курируемых набора (A/B) + **снимки пользователя** (друзья, семья). У кадра две настройки: фаза и плотность вуали; флаг «беречь лица» сдвигает контент ниже линии лиц. Экран библиотеки и настройки кадра — `Fitness Backgrounds.dc.html` (сетка 9:16, первая плитка — загрузка, галочка = активный, иконка человека = свой снимок).
Правило подбора: светлой теме нужны кадры яркостью > 55 % со спокойным верхом, тёмной — с глубокими тенями.
