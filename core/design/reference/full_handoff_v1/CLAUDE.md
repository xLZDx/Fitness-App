# Fitness app — общий дизайн (утверждён)

Базовый стиль всего приложения: **парящее HUD-стекло** поверх фотографии.
Эталон — `Fitness Form Coach Phone.dc.html`; сравнение тем — `Fitness Screens 50-50.dc.html`.

## Файлы-источники
- `Fitness Glass Phone v1 - Sunset.dc.html` — тёмная тема, 6 экранов (Home, Workouts, Scan, Progress, Profile, Session).
- `Fitness Glass Phone v1 - Light.dc.html` — светлая тема, та же вёрстка.
- `Fitness Form Coach Phone.dc.html` — экран тренера (видео + подсвеченный скелет).
- `Fitness Sky.dc.html` — фон: `variant="photo"`, смена кадра по часам устройства, кроссфейд 1,6 с.

## Формула стекла — тёмная тема
```
background:rgba(255,255,255,.014);
backdrop-filter:blur(7px);
box-shadow:inset 0 0 0 1px rgba(255,255,255,.34),0 0 26px -6px rgba(255,255,255,.26);
text-shadow:0 1px 14px rgba(6,8,18,.85)
```
Кнопка (самый светлый элемент): заливка `.05`, контур `.46`, свечение `0 0 28px -8px rgba(255,255,255,.35)`, подъём −2 px на ховере.
Мелкие чипы: заливка `.02`, контур `.28`.

## Формула стекла — светлая тема
Тот же приём с обратным знаком: заливка `rgba(255,255,255,.3)`, blur 14 + saturate 150 %, двойной контур `inset 0 0 0 1px rgba(255,255,255,.85)` + `0 0 0 1px rgba(27,32,48,.16)`, тень текста белая `0 1px 12px rgba(255,255,255,.9)`.
Кнопка: заливка `.46`, чернильный контур `.3`. Текст `#1b2030`, вторичный `rgba(27,32,48,.62–.8)`.

## Геометрия
Радиусы: корпус 26, панели 30, вторичные панели 24–28, кнопки и чипы 20–22, круглые счётчики — `border-radius:50%`, 158×158.
Никаких плотных заливок: форму держит контур, не фон.

## Цвет и типографика
- Акцент тёмной темы `#C9FF47`, светлой `#4B7A00`. Состояния: норма `#7BF08A`, ошибка `#FF5A5A`.
- Шрифт Archivo. Крупные числа — вес 400 в 34–72 px со свечением (вес даёт контраст, а не жирность), единицы и метки — ui-monospace 9–11 px, letter-spacing .1–.2em, uppercase.
- Раскладка — flex/grid + gap, не отступы по элементам.

## Фоны
Шесть фаз суток (ночь / рассвет / утро / день / золотой час / сумерки), два набора кадров A и B (`photoSet`), плюс пользовательские снимки. Библиотека и настройка кадра — `Fitness Backgrounds.dc.html`. Светлой теме нужны кадры яркостью выше 55 % и со спокойным верхом, тёмной — с глубокими тенями.

## Правила
- Экран телефона 390×844.
- Хит-таргеты не меньше 44 px.
- Новые экраны собирать внутри существующих файлов тем, а не отдельными копиями.
- Дизайн-система проекта — Modernist; обзорные/презентационные страницы (`Fitness Screens 50-50`, `Fitness Backgrounds` и т. п.) строятся на её токенах, сами экраны приложения — на HUD-формуле выше.
