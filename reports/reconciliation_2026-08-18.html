One row, and what it cost

N05_DISPOSITION.md:164 carried F-prefetch as OPEN, recorded: "resolveAll still swallows a quota refusal; a prefetch stopped by the cap reports nothing. Needs a result type that can say 38 of 84, limit reached." That was true when it was written. It was not true at ASSESSMENT_HEAD, and it had not been true for some time. resolveAll does not exist anywhere under lib/. It became resolveBatch returning ClipBatch, which the prefetch layer converts into PrefetchOutcome, whose five mutually exclusive PrefetchState values include partialQuota — the exact sentence the row asked for. Both the fix and a later correction to it are recorded in the decision log.

The failure mode here is worth stating precisely, because it is not laziness. The log is append-only and was correct. The source was correct. The tests were green and stayed green. The only wrong artefact was the one a reader opens to ask what is still open, and it was wrong in the expensive direction: it claimed work remained that had already been done. A final report assembled from that table would have listed a closed defect as outstanding, and not one test in the repository would have objected — because no test reads a status table.

The row now cites its replacement symbols by file and line, so the claim is checkable rather than asserted, and carries an explicit note that it changed because the symbol is gone from lib/ — not because time passed. An OPEN row does not age into a FIXED one.

Three guards that could not have failed

The second half of the sweep asked one question of every guard added this session: could the set it iterates be empty, and would the test still pass?

Three could, and would. A guard that passes on an empty subject is not a weak guard; it is a guard that has never once been consulted, wearing the colour of one that has.

AP · the pin emptied

test_every_pinned_digest_is_a_sha256 loops over PINNED. Empty it and the loop body never runs — and the same emptiness silently satisfies len(verified) == len(artifacts) + len(corpora) as 0 == 0.

Killed by appending PINNED["corpora"] = {}.

AQ · the document gutted

test_no_digest_…_the_pin_does_not_hold asserts quoted - known is empty. A document quoting nothing produces an empty difference and a pass. Its counterweight is @needs_pipeline and skips without the model bytes — so on that machine nothing at all stood between a hollowed-out document and a green suite.

Killed by stripping all eleven abbreviated digests.

AR · the reason set emptied

Five Dart assertions iterate knownReasons. The strictest-looking is the worst: hasLength(knownReasons.length + 2) reads as a derived count and degenerates to 2 == 2.

Killed by deleting one wire reason from the client map — 3 failures.

All three were fixed by asserting the subject once, not by repairing five loops. On the Dart side the assertion names the values rather than counting them — the reasons must map onto exactly the CheckoutRefusal set minus the three that exist without a wire value — because a count invites the arithmetic to be adjusted to whatever the code now does.

One invalid mutation, recorded rather than quietly rerun. The first attempt at AP replaced "corpora": { with "corpora": {} or {. In Python an empty dict is falsy, so {} or {…} evaluates to the second operand: the pin was never emptied, and the green run that followed proved nothing whatsoever. It is reported here because a mutation harness that hides its own invalid mutants produces exactly the false confidence it was built to detect.

Disposition

Every control proposed to satisfy N-05 must survive deleteAccount to function, which contradicts the published privacy policy at public/privacy.html:87-88,93.
