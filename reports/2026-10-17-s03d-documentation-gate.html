What the design contract now says, in plain words

  • One app. Phase 2 ships as an update of the same app with the same application id, not as a second app.
  • Five tabs stay. "Record" is a button over the screen, not a replacement for the Scan tab.
  • Window sizes. Narrow (under 600 dp): bottom bar. Medium (600 to 839): bottom bar with a width cap. Wide (840 and up) and short windows (under 480 dp high, such as a phone on its side): a side rail on the left instead of the bottom bar. The class comes from the window width, not the device type, so iPad split screen and a resized Mac window behave the same way.
  • Screens on big windows. Home, Progress and Sources get two columns only when the content area is at least 880 dp wide (after the rail); otherwise one column. The mode chooser gets a description panel on the right on wide windows.
  • Per device family. Android: Material. iPhone, iPad and Mac: Apple-style gestures, sheets and popovers; on Mac also mouse, hover, keyboard and a menu (default window 1100x760, minimum 480x600).
  • Apple builds. Design only for now: the repository has only an android folder. When to create iOS, iPadOS and macOS builds is not decided.
  • The local activity journal always opens, regardless of the cloud flag. In the code it is off by default today; turning it on is the first task of S03 (story S03-0).
  • Cloud GPS route retention: 90, 365 or 730 days, default 730 (two years). There is no "never".

What I missed, in plain words

  • The privacy page was hand-edited in three commits (two of them in S02, from briefs of mine that did not name the source) although its source is a generator. I also wrongly believed the source was the app strings file. New rule: before editing a file under public/, find its generator, and name the source file in every agent brief.
  • A contradiction in the mode chooser grid. Two internal reviewers checked what I pointed them at but not the older rule from revision 2; only the external one caught it. Now every "N items in a row" rule in a contract carries its check with numbers, and reviewers are told to recompute inherited text too.
