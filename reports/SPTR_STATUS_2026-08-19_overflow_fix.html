01 What was found and fixed

Visual defect

While investigating programme-card density on the Workouts tab, a test account with chest pain answered "yes" tapped "Start programme". The resulting refusal dialog (programme.enrol.blocked) rendered a real device render error:

BOTTOM OVERFLOWED BY 271 PIXELS

The lower PAR-Q+ questions were clipped off screen — physically unreadable.

File
mobile/lib/features/workouts/workouts_page.dart
Cause
EligibilityNotice inside a Dialog with no ScrollView
Test
mobile/test/features/workouts_page_test.dart
Commit
4cfac26

Root cause. Chest pain is a blocking answer (F017), and the screen honestly stops asking after it — six of seven PAR-Q+ questions stay incomplete. EligibilityNotice renders one bullet per reason with no scroll of its own — correct where it is already embedded in a scrolling list (the Workouts tab, the exercise list), wrong for a plain Dialog, which does not supply one either.

Fix. Wrapped the dialog's content in ConstrainedBox(maxHeight: 80% of screen) + SingleChildScrollView — a long reasons list now scrolls inside the dialog instead of overflowing it. EligibilityNotice itself was not changed.
