Parity, proved by measurement rather than by eye

All three cells share one layout, one stylesheet, one section count, one CTA and one image set — only the headline and its single supporting sentence differ. Objective check: initial transfer is 142 KB for all three cells at both viewports, byte-identical, because nothing but two text nodes changes between them.

02

No usable product footage exists — so none was invented

The repository's only app screenshots are debugging artefacts from 30 July 2026. One shows the old on-device classifier calling two flat benches a treadmill at 100% confidence; another is a PlatformException stack trace. Both predate the cloud recognition path. Using either as product evidence would have been false in the opposite direction, so neither was used, and no screenshot of the app appears anywhere on the site.

What was usable: the operator's own gym photographs. All four site images are crops from them, chosen to exclude identifiable people — the source set contains gym members whose faces are recognisable and who have not released them.

The strongest asset in the build was already on the gym floor

The evidence section uses a real Nautilus placard reading PEC FLY / REAR DELT, photographed on a real machine. That is the exact mechanic being claimed — documented, not illustrated. Six rounds of argument about whether auditable identification is real, and the proof was sitting in a photo folder.

Where product behaviour still has to be depicted, it is a labelled illustration built from the app's own shipped strings — Not sure — closest matches, Not in the catalog yet, scanned 3 times, Read on the machine — quoted verbatim from the ARB files rather than written for the page. Four slots are flagged in the implementation report as needing real footage before public use.

03

Claim classes live in the markup

Every classified sentence carries data-claim-class in source. Under ?debug=1 each renders an inline badge, and media blocks reveal whether they are a real photograph or an illustration. A claim added without a class does not appear in the register's regeneration output — which is the intended failure signal for the pre-public gate.

The copy was written around that — "the setup you saved for it — seat, pad, pin, or whatever that machine actually has" — because real equipment carries numbered detents, letters, unmarked holes, or nothing.

Six defects found and fixed in review

The one that mattered

An author display: grid on the debug panel outranked the user-agent rule for [hidden], so the internal R&D switcher rendered for every visitor — concept and language controls included. Fixed with an explicit .debug[hidden] { display: none }. A specificity accident, invisible in code review, caught only because the first full-page screenshot showed a control that should not have been there.

The others: a missing favicon producing a console 404; a <button> styled as a link inheriting neither the page font nor a pointer cursor; a final CTA that scrolled to top instead of recording intent; srcset descriptors left stale after images were re-encoded, a layout-shift source; and one generated image that was never referenced, deleted rather than shipped as dead weight.

Two harness defects, recorded so they are not mistaken for site defects

Blank sections in the first full-page capture. The page sets scroll-behavior: smooth, so the QA script's programmatic scroll outran the real scroll position and the reveal observer never fired below the fold. The site was never affected.

ERR_CONNECTION_RESET on mobile. Only ever produced when the harness scrolled the whole page in 90 ms bursts, flooding a single-process test server. Re-tested under a normal wheel scroll: zero console errors, zero non-200 responses, all images complete.

05

Found while building

  • The exercise clips are not bundled. assets/exercises/ was removed from pubspec.yaml on 2026-08-04. Clips stream from cloud storage over a signed URL with a bundled still as the instant fallback. The demonstration-video claim is true and network-dependent — the register now forbids ever phrasing it as "works offline".
  • Progression is genuinely wired. suggestNextWeight() is not an orphan function — it renders a tappable suggested weight in workout_player_page.dart:1258, which is why that claim sits in exists rather than committed.
  • Russian is a localisation, not a translation. Point. Recognize. Continue. became Навести. Узнать. Продолжить. — infinitives, because the natural imperative forces a formality choice and the past tense forces a gender. That makes the Russian heroes separate stimuli that must not be pooled with the English cells when testing.
