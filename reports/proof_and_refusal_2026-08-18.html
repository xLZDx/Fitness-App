The standard of proof

A green suite proves that a suite ran. It does not prove that any test is attached to the behaviour it names.

Every guard in this session was mutation-tested

Break the guarded subject, confirm the guard fires, restore the file byte-for-byte and confirm the restore. A mutant that fails to compile is discarded rather than counted: it proves the compiler works, not the test. Twenty-one mutations were killed this session across eleven code gates, plus one invalid kill rejected, one correct survivor, and two survivors that turned out to be defects in the tests themselves — which is the outcome that pays for the whole technique.

Three defect shapes kept recurring

A fixture that guarantees its own outcome. A cache-margin test compared Duration(minutes: 13) to Duration(minutes: 15) — two literals in a test file measuring themselves, blind to what the implementation actually caches for, which is the exact regression its own comment said it existed to catch.

A guard that matches prose rather than behaviour. A zero-delivered quota line was asserted with contains('limit') and contains('tomorrow') — both true of a different string, so substituting the wrong one stayed green.

A guard that reads a key the producer never writes. Or its mirror: a checker that read adjacency in a serialized file as if adjacency were a statement.

The finding that mattered most

A comment that asserted a guarantee the system does not provide, and the code that acted on it.

The chunk loop gave up on clips it could still have had

A week's prefetch is chunked at sixty objects per call. On the first quota refusal the loop stopped, and the comment justified it: "the budget is per-day and per-account, so every remaining chunk would be refused too."

The backend does not work that way. enforceDailyQuota refuses on used + cost > limit, and the batch endpoint passes the chunk's own length as cost. A refusal therefore proves only that that chunk does not fit in what is left — and the last chunk of a prefetch is usually the short one. An account 1,190 objects into a 1,200 budget still has room for a trailing chunk of ten, and the early stop threw those away while telling the user the limit had made them unobtainable.

A refused chunk is also charged nothing: the transaction throws before it writes. So the price of continuing is one wasted round trip per remaining chunk, at most three on a 200-clip week. The loop now continues, the comment states the model instead of asserting a conclusion, and a fixture that mirrors used + cost > limit proves the trailing chunk lands.

The same evidence rejected a different reviewer's request

A reviewer asked for the download control to be disabled while quota-exhausted, on the grounds that retrying is a no-op. Under used + cost > limit it is not: a second run asks for fewer references, and fewer can fit. Disabling the control would have denied a retry that can succeed. Recorded as rejected, with the reason, rather than quietly dropped.

Refused, and why refusing was correct

The instruction was to maximise proven work, not to maximise closed tickets. These are the places where the honest output was a written refusal.

Three metric claims in Russian prose not fixed The source states the values under Russian labels. Locating them needs a translation table, and a translation is a claim about meaning that only the document's author can make. Recorded with what would close it.
Two complement claims not fixed The source says thirty of thirty passed; the registry says zero rejected. Right, and textually absent. A locator that derives one complement can be argued into deriving others.

Invariants that were required to survive, and did

Checked, not assumed. None of the work below moved any of these.

  • Engineering remediation baseline — frozen.
  • Continuous retraining — not operational; training and deployment remain separate concerns.
  • Human labels — zero, and none invented.
  • External clinical validation — still required; nothing here reviewed anything clinically, and the submission path still closes nothing on its own.
  • Untagged exercises — not flipped to fail-closed. No agent was permitted to invent the clinical semantics of the untagged rows.
  • Production image collection — disabled.
  • The challenger model — not shipped, not promoted, not bundled.
  • Anonymous login — not silently removed. The guest path was made reachable, which is the opposite change.
  • Train and holdout label sets — disjoint, with no training label sourced from a model prediction, an automatic flag, a holdout human label, or a synthetic review.

What a reader should not take from this

Twenty-one killed mutations are evidence about twenty-one specific behaviours. They are not a statement about the codebase. Nothing here was reviewed by an independent second opinion; the reviewers used were internal, and their strongest findings were confirmed by reading the backend rather than by agreement.

The Cloud Functions suite was not re-run and no number is quoted for it. No file under the functions tree changed in this session, and stating a figure from a run that did not happen is precisely the failure mode this report is about.
