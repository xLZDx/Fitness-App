Код (form_check_page.dart)

  1. Демо больше не останавливается. Флаг demonstrating теперь истинен всё время работы режима аватара, а не только до первого повторения: ref.watch(avatarModeProvider) || (_started && session.repCount == 0 && session.phase == RepPhase.top). Режим без аватара не тронут — там демо по-прежнему уступает место статичной цели, как только начинается движение (это отдельная, тоже рабочая функция).
  2. Силуэт больше не прячется в режиме аватара. Убрана строка if (ref.watch(avatarModeProvider)) return const SizedBox.shrink(); — раньше она специально гасила силуэт, потому что при совместном показе фигуры оказывались на разных масштабах (полноростовой призрак поверх экрана «тело не найдено»). Теперь это устранено не костылём, а по построению: силуэт показывается либо когда тела в кадре ещё нет вовсе (не с чем конфликтовать по масштабу), либо когда демо-цикл идёт как заведомо отдельный, независимо отмасштабированный ориентир.
  3. Найденный баг: прыжок масштаба. Как только демо стало крутиться непрерывно, обнаружилось (не предполагалось заранее, а увидено на устройстве): фигура каждый кадр анимации подгонялась под собственные, каждый раз новые, границы промежуточной позы — и визуально «прыгала» в размере на каждом цикле. Исправлено параметром fixedBounds: теперь масштаб считается один раз — как объединение границ обеих крайних поз цикла — и не меняется всю анимацию.

Проверка на устройстве

S8 (ce02171299f0711005), свежая debug-сборка, явный force-stop и перезапуск. Маршрут: Тренировки → Библиотека → фильтр «Тренер по технике» → «Начать» → «Готово — включить камеру» → экран с камерой, до нажатия «Начать подход». Восемь скриншотов подряд (~0,5 с между кадрами) через половину цикла присед → стоя — масштаб и положение фигуры стабильны на всех кадрах, ни разу не сломался силуэт (раньше в похожей ситуации фигура визуально теряла торс и голову — этот артефакт здесь не воспроизвёлся ни разу).
