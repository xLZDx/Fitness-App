8. Dependencies

  • E0 → E1, E3–E7: Foundations (deploy guards, runtime, module visibility) are required by every later increment.
  • E1 (команды) → E2 (голос, запись), E7 (удаление, экспорт): Any voice mutation goes through the one command path; deletion and export must know the queue.
  • E1 миграция (DRAIN) ← PITR + аудит-логи + шаг «начать удаление» + мин. версия приложения: Without these four preparations the legacy data migration does not start.
  • E4 (карта зала, ADR) → E5 (видео, геометрия, маршруты): The map extension needs the approved base and the map value check.
  • E3 фото еды ← решения оператора Q-4, Q-5, Q-6, Q-10 и реальный детектор лица: Nutrition and scan flags go on only after these gates.
  • P1-S5 выпуск ← P1-S2 (Stripe, магазин) + P1-S3 (устройство) + P1-S4 (клиника): Store release R1 is impossible without the previous three.
