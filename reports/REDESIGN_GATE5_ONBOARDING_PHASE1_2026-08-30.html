The key engineering call

A new title widget, not a restyle of the old one

StepTitle is used across all 11 onboarding step files — confirmed by grep before any code was touched. Restyling it in place would have silently reskinned the 4 frozen safety screens (body, healthFlags, screening, preview) this gate has no authority to touch. So a separate OnbRefTitle was built on the HudType.bigNumber(size:32) token — the same glow-typography recipe the reference uses for its own headings — and wired only at the 4 call sites GPT-PM approved.

The same blast-radius check applied to ChoiceCard (only 2 call sites, both in Phase 1 — safe to restyle in place) and to HudChip (shared with form_check_page.dart, workouts_page.dart — left untouched; it already draws from the t.chip/t.accentChipGradient tokens that already match the reference, so GPT-PM's "weekday chip restyle GO" was already satisfied with zero code changes).
