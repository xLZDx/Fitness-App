06 Оговорки по актуальности данных

Мастер-план (core/MASTER_PLAN_2026-08-26.md) — основной документ, но не полностью синхронизирован с реальностью:
  • Датирован 2026-08-26, с одной дозаписью 2026-09-15 (§12). Пункт 1 (targetSdk) в его собственной таблице всё ещё читается как открытый, хотя MVP1.G2 закрыл его ещё 2026-08-27 — документ просто не обновили после этого гейта.
  • Не отражает работу этой недели: P2.G5-readiness шаг 3a (закрыт сегодня, 09-16), финальный статус P2.G4.
  • Не упоминает FORM_COACH_HUD_ALIGNMENT как отдельный гейт вовсе — тот появился в pm_gate_status отдельно от мастер-плана.
pm_gate_status (реестр PM Bridge) тоже был неполон: не содержал отдельных записей для P2.G1–P2.G4 — те гейты закрывались только через core/DECISION_LOG.md, без pm_set_gate. Полностью закрыто той же сессией, 2026-09-16: все четыре гейта доверифицированы напрямую по их собственным Rosetta-записям и забэкфиллены в pm_gate_status — P2.G1/P2.G2/P2.G4 как passed (реальные closure-review APPROVE), P2.G3 намеренно как in-progress, а не passed — его собственная запись закрытия прямо говорит, что закрывает только implementation-план и держит мастер-гейт OPEN/DEPLOYMENT_PENDING до отдельно авторизованного реального деплоя.
