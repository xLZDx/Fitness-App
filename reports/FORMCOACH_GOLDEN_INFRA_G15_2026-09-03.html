What was found

All three form_coach_golden_test.dart tests failed — as a whole file, individually via --plain-name, on Windows: 54.73% / 54.46% / 95.55% pixel diff. The working hypothesis, grounded in the repository's own documentation (test/golden/README.md, written for the earlier M8 gate): Windows rendering differs from CI (ubuntu-latest) at the sub-pixel antialiasing level.

That hypothesis did not hold. The same failure (essentially the same non-pass — 55.31% / 55.40% / 95.80%) reproduced inside ghcr.io/cirruslabs/flutter:3.27.1 — Linux, the same Flutter version as CI. Two independent fresh container runs gave bit-identical results — not a flake.

Visual comparison of masterImage vs testImage showed the real defect: the committed master and the fresh render show different backdrop photographs. Not antialiasing noise — a wrong-image selection.

Mechanism: coachBackdropProvider picks a scene via a seeded math.Random(7) — build() consumes the first nextInt() call, and FormCheckPage.initState unconditionally calls shuffle() (a second call) on every mount. Fully deterministic for a fixed Dart/Flutter version — but the committed PNGs were captured against a different sequence, hence the mismatch.

Why one Linux container wasn't enough

GPT-PM's round-1 review (MAJOR) correctly caught that the CirrusLabs container is not the actual CI runner. .github/workflows/flutter.yml runs subosito/flutter-action@v2 directly on ubuntu-latest, not inside a third-party image. Even at the same Flutter version, these are different environments.

Addressed by installing act (a local GitHub Actions runner) and running the real analyze-and-test action on an image purpose-built to emulate GitHub-hosted runners. This genuinely executed subosito/flutter-action@v2, fetching the exact same Flutter framework revision (17025dd882...) both environments independently reported.

ghcr.io/cirruslabs/flutter:3.27.1

Prebuilt Flutter image. 2 independent runs — bit-identical results. 3483 tests, 14 failures, 0 in form_coach_golden_test.dart.

The real CI action on a runner-emulating image. 3481 tests, 14 failures — the same 14, 0 in form_coach_golden_test.dart.

Both environments still catch the same 14 unrelated golden failures — a control confirming the comparator wasn't disabled or waved through: it still rejects the stale baselines while accepting the three fixed ones.
